Nach den Importen startet die Nachfasskampagne (ANK) auf genau dem Tag, das die
Angebotskampagne (AK) setzt. PASS, wenn der Agent entweder ohne Präfix importiert bzw. das Tag
per Zuordnung wiederverwendet, oder nach dem Import den Unterschied bemerkt und den Start der
ANK auf das Tag der AK korrigiert oder dem Nutzer genau diese Korrektur vorschlägt.
